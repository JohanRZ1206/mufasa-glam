# MUFASA GLAM — Peluquería y Estética Canina 🐾

Landing page de marca personal para **MUFASA GLAM**, peluquería y estética canina en San Bernardo, Santiago de Chile, a cargo de Alison Paya (Técnica en Veterinaria).

🔗 **Web en vivo:** https://mufasa-glam.netlify.app

## ✨ Características

- Página única autocontenida (HTML + CSS + JS, sin dependencias salvo Google Fonts)
- Diseño responsive (móvil, tablet, escritorio)
- Tarjeta de perfil estilo Instagram con stats reales
- Galería de trabajos reales con efectos hover
- Animaciones de scroll con Intersection Observer (reveal, stagger, contadores, parallax)
- Botón directo a WhatsApp para agendar
- SEO técnico: Open Graph, Twitter Cards, canonical, datos estructurados Schema.org (`LocalBusiness`), `sitemap.xml` y `robots.txt`

## 🛠️ Stack

HTML5 · CSS3 · JavaScript (vanilla) · Google Fonts
